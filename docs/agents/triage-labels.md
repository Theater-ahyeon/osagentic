# Triage 标签

skill 使用五个规范 triage 角色。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| 规范角色（mattpocock/skills） | 本 tracker 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估此 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整指定，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

当 skill 提到某个角色（例如"应用 AFK-ready triage 标签"）时，使用上表对应的标签字符串。

编辑"本 tracker 标签"列以匹配你实际使用的词汇。
